# change-plan-ready

确认变更分析满足已加载的 `change-execution-policy`，并已在第一次写入前向用户展示。计划必须包含明确目标、范围内事项、范围外事项、预计修改文件、主要风险、验证方式以及接口与文档影响。

按通用协议判断任务是否属于非平凡任务：

- 非平凡任务的 evidence 必须包含 `planPath=<相对 Workspace Root 的路径>`；完整读取该计划文件，确认路径位于目标 Workspace、内容与已展示计划一致、包含全部必需章节，且不包含 Secret 或完整 Prompt。
- 简单任务没有计划文件时，evidence 必须包含可核对的未落盘原因，并确认任务没有公开 Interface、Schema、迁移或发布影响。
- 接口与文档影响不得省略。存在影响时，必须列出机器事实源、面向使用者的说明路径和兼容性影响；没有影响时明确写“无”。

信息足以进入实现且没有待用户决定的问题时返回 `passed`；可以通过继续只读调查补齐时返回 `needs_changes`。需要用户决定、权限或不可逆选择时先保持当前 Step 并询问，不得在询问前进入实现；只有无法通过用户回答继续时才返回 `blocked`。必须包含可核对的 `evidence`。
