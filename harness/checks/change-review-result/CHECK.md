# change-review-result

确认 Review 基于实际需求、已展示的计划、实际 Diff、测试和 Runtime 命令证据，并检查正确性、回归、兼容性、依赖和生成物。

从 Runtime 聚合 evidence 中定位 `planPath=`。存在时完整读取计划文件，并确认实际修改文件和行为没有超出计划范围；简单任务没有计划文件时，确认 evidence 中的未落盘原因仍成立。实现期间扩大范围或改变接口文档影响时，必须先更新计划并向用户说明。

对照计划中的接口与文档影响检查实际 Diff：新增或修改公开 Interface、Schema、CLI、事件或配置契约时，机器事实源、面向使用者的说明、兼容性或迁移说明和适用测试必须同步更新。不得只修改 Markdown 而遗漏机器事实源，也不得复制可由机器事实源表达的字段结构。

修改可执行代码或配置时必须存在适用测试成功证据。

没有阻断性交付问题时返回 `passed`；存在当前范围内可修复的问题、范围外改动或缺少测试证据时返回 `needs_changes`。需要用户决定时按通用执行协议暂停询问；外部条件无法解除时返回 `blocked`。必须包含文件、位置或 Runtime 证据。
